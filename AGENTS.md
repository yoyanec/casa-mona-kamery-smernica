# Casa Mona — smernica o kamerovom systéme

Jednostránková smernica (index.html, Bootstrap z CDN) publikovaná cez GitHub Pages z vetvy main
repozitára github.com/yoyanec/kamery.bilka.sk na adrese https://kamery.casamona.sk/ (súbor CNAME;
Cloudflare: proxied CNAME kamery → yoyanec.github.io v zóne casamona.sk).

- Obsah je formálna slovenčina, právna terminológia GDPR a zákona č. 18/2018 Z. z.; pri zmene pravidla
  upraviť aj dátum účinnosti.
- Jeden HTML súbor bez build kroku; nové štýly a skripty do samostatných súborov, nie inline.
- Zmeny cez feature vetvu a PR; main je publikačná vetva Pages.
